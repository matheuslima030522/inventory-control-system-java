# Inventory Control System - Java

This project is a simple inventory control system developed in Java, applying Object-Oriented Programming (OOP) principles.

## 📌 Features
- Product registration
- Product listing
- Search product by name
- Quantity control

## 🛠 Technologies
- Java
- Object-Oriented Programming (OOP)

## 🎯 Purpose
This project was created to practice OOP concepts such as classes, encapsulation, and object management.
